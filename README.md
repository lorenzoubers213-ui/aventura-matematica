# Aventura Matemática
App web/PWA de matemáticas.
- 1.º a 11.º grado
- 10 niveles por grado
- 20 preguntas por nivel
- Nivel 1 de cada grado desbloqueado desde el inicio
- Niveles posteriores desbloqueados al completar el anterior del mismo grado
- XP, monedas, racha y guardado local
- Compatible con PC, tablet y teléfono
- Créditos: App desarrollada por Ryan Salazar, Sara Mairena y Jostin Obregon
